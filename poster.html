Mastering Command Terms in Legal Studies

From Stating Facts to Building Judgments

Level 1 · Foundation

Describe / Identify · The What
Core Meaning
State key features, characteristics or facts clearly — without giving an opinion.
Prompt Structure
[Command Term] + [Legal Concept / Institution / Law]
Response Formula
Fact 1 + Fact 2 + Key Detail / Example
Thinking hint: Paint a picture with facts.

Level 2 · Analysis

Analyse / Compare · The How & Why
Core Meaning
Break a concept into parts, explain relationships, or highlight similarities and differences.
Prompt Structure
[Command Term] + [How / Why] + [Impact on Legal System]
Response Formula
Identify Component → Explain How / Why → Link to Impact
Thinking hint: Show how the gears connect.

Level 3 · Evaluation

Evaluate / Justify · The Judgment
Core Meaning
Weigh strengths and weaknesses and reach a justified verdict.
Prompt Structure
[Command Term] + [Effectiveness / Value / Extent] + [Legal System / Law]
Response Formula
Definition → Strengths → Weaknesses → Justified Verdict
Thinking hint: Weigh the scales before landing on a verdict.
GOLDEN RULE: Match your response to the command term.

How to Use This Poster

  1. 1
    Find the command term in the exam question and match it to Level 1, 2 or 3.
  2. 2
    Follow the response formula so your paragraph structure matches the cognitive demand.
  3. 3
    Check your answer against the golden rule before you move on.
